## 🚗 Blitz Vision Craft 소개
**Blitz Vision Craft**는 VR기술을 활용하여 실시간으로 RC카를 조종할 수 있는 혁신적인 졸업작품입니다. **esp32 보드**와 **ffmpeg 통신**을 사용하여 조종기와 차체 간의 원활한 소켓 통신을 구현하고, 웹캠 영상을 실시간으로 송출하여 VR 화면으로 변환하여 사용자에게 몰입감 있는 조종 환경을 제공합니다.

### 🎯 주요 기능
- **실시간 영상 송출** 📹: ffmpeg를 사용해 웹캠 영상을 실시간으로 송출하고, 이를 VR 화면으로 변환하여 사용자에게 생생한 조종 환경을 제공합니다.
- **정밀한 조종** 🎮: 조종기를 통해 RC카를 정밀하게 조작할 수 있습니다.
- **실시간 VR 조종** 🕶️: VR 기술을 활용해 차체에서 보내는 영상과 사용자 조작을 실시간으로 반영하여 조종합니다.
